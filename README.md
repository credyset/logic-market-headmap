# Logic Market Heatmap

Shareable working project for Logic's two market heatmaps.

Open `index.html` for the two-tab view:

- **Agency** — supply-chain and operations evidence for scaling consumer brands.
- **Pac** — packaging-led evidence across design, materials, manufacturing, retail performance, and fundraising.

The two maps are intentionally separate. Counts are corpus signals, not market-size estimates. Pac fundraising evidence is explicitly limited and documented as a research gap.

## Project structure

Each arm's interactive report is its tab landing page. Supporting summaries, topic CSVs, language/claims material, and taxonomy/method notes remain available in the respective folder.

The additive category layer now covers luxury goods, jewelry, elevated DTC packaging, influencer/PR kits, consumer electronics, headphones, babytech, wine and spirits, and beauty. See `aligned-category-expansion-2026.md` for the current synthesis and remaining evidence gaps.

## Review workflow

Use the tabs and linked files as the shared review surface. Add feedback through GitHub Issues or pull requests; keep Agency and Pac changes in their respective folders.

## Evidence standards

Podcast quotations must satisfy the complete attribution standard in `quote-attribution-standard.md`. Unverified excerpts are retained for research, while outreach one-liners are published only as editorial paraphrases in `outreach-painpoint-insights.csv`.
